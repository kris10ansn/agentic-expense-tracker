- Prefer immutable variables
- Prefer early returns over large if/else logic

- Avoid ternaries unless very convenient
- Avoid inline function props unless very simple
- Avoid excessive nesting of if statements and similar
- Avoid switch statements
- Avoid code blocks without curly braces

- Have space between logic

- Tailwind: avoid using specific pixel numbers and sizes specified in square brackets - try to use the predefined sizes where possible
