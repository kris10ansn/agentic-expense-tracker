# AI Expenses

TypeScript monorepo for expense tracking and AI extraction from text and images. Use Bun for workspace commands.

- `apps/api` owns the tRPC backend and database.
- `apps/web` owns the React browser UI.

For setup, commands, and verification, see [README.md](README.md).

All code should follow the code style guidelines: [CODE_STYLE.md](docs/CODE_STYLE.md)

Branch naming: [BRANCHES.md](docs/BRANCHES.md)
